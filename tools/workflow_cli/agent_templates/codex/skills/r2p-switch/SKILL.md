# r2p-switch

Run `{{R2P_BIN_DIR}}/r2p-switch` to change the selected active run.

Usage: `{{R2P_BIN_DIR}}/r2p-switch --work-id <id>`

Use `r2p-status --all` to discover available work IDs.
